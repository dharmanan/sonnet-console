# Notices

Sonnet Console is an independent community tool for the FLOP / Technocore Sonnet Challenge.

Protocol behavior is implemented against the public `flop-labs/technocore-sonnet-challenge` rules and launch configuration.

The project architecture was also informed by the MIT-licensed community project `UfukNode/technocore-sonnet-team-desk`. Sonnet Console uses its own source files and adds a different identity model plus explicit cryptographic verification of referee room messages.

CMUdict is used from the exact frozen upstream revision pinned by the contest. Its original copyright and redistribution terms remain applicable.
